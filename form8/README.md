# CHC HMIS · Form-8 — ડેટા એન્ટ્રી + Excel એક્સપોર્ટ

CHC (Community Health Centre) માં HMIS Form-8 ના રોજિંદા આંકડા ભરવા અને મહિનાના અંતે
એક જ ક્લિકે **Excel (.xlsx)** કે **CSV** ફાઇલમાં બહાર કાઢવા માટેનું સાધન.

બે વિકલ્પ છે — જે ગમે એ વાપરો:

| ફાઇલ | શું છે | ક્યાં વાપરવું |
|---|---|---|
| `index.html` | મોબાઇલ/કોમ્પ્યુટરમાં ચાલતી એપ (ઓફલાઇન, કોઈ ઇન્ટરનેટ કે લાઇબ્રેરી નહીં) | રોજનો ડેટા ભરવા — iPhone પર પણ ચાલે |
| `form8-template.xlsx` | તૈયાર Excel ટેમ્પલેટ (SUM ફોર્મ્યુલા સાથે) | હાથે/Excel માં જ ભરવું હોય તો |

## 1. એપ (`index.html`) કેવી રીતે વાપરવી

1. ફાઇલ ખોલો (Safari/Chrome — નીચે "iPhone પર કેવી રીતે ખોલવું" જુઓ).
2. **ફેસિલિટીનું નામ, તાલુકો, ભરનારનું નામ** લખો.
3. **મહિનો / વર્ષ** પસંદ કરો — દરેક મહિનાનો ડેટા અલગ સેવ થાય છે.
4. ટેબલમાં દરેક દિવસની પંક્તિમાં આંકડા લખો. નીચે **કુલ** આપોઆપ ગણાય છે.
5. અંતે નીચેના બટન દબાવો:
   - **⬇️ Excel (.xlsx)** → `Form8_<ફેસિલિટી>_<વર્ષ-મહિનો>.xlsx`
   - **⬇️ CSV** → Excel/Google Sheets માં ખૂલે એવી ફાઇલ

### કોલમ બદલવી (મહત્વનું)
તમારા વિભાગના Form-8 માં કોલમના નામ/આંકડા અલગ હોઈ શકે. એટલે:

* **વિભાગ 3 → કોલમ સેટિંગ** ખોલો.
* દરેક કોલમનું નામ બદલી શકાય, પ્રકાર **આંકડા / લખાણ** પસંદ કરી શકાય.
* **+ નવી કોલમ ઉમેરો** થી Form-8 ના જેટલા કોલમ હોય એટલા ઉમેરો.
  જે કોલમનો સરવાળો ન થવો જોઈએ (દા.ત. તારીખ) એ "લખાણ" રાખો.
* ફેરફાર પછી એક્સપોર્ટ કરેલી Excel માં પણ એ જ કોલમ જ આવશે.

### ડેટા ક્યાં સેવ થાય?
* ડેટા **તમારા જ ફોન/બ્રાઉઝરમાં** (localStorage) સેવ થાય છે — કોઈ સર્વર પર જતો નથી.
* એટલે બ્રાઉઝરનો ડેટા/હિસ્ટ્રી સાફ ન કરવો. મહિનાના અંતે
  **બેકઅપ ફાઇલ સેવ કરો (.json)** દબાવીને બેકઅપ રાખવો; પછી ક્યારેય
  **બેકઅપ પાછો લાવો** થી પાછો મેળવી શકાય.

### iPhone પર કેવી રીતે ખોલવું
* સૌથી સહેલું: રેપોની GitHub Pages લિંક (જો ચાલુ હોય) Safari માં ખોલો →
  Share → **Add to Home Screen**, પછી એપની જેમ વાપરો.
* અથવા `index.html` ડાઉનલોડ કરીને **Files** એપમાં સેવ કરો, પછી એ ફાઇલ
  Safari માં ખોલો.
* પહેલી વાર ખોલો પછી ઇન્ટરનેટની જરૂર નથી.

## 2. Excel ટેમ્પલેટ (`form8-template.xlsx`)

* 1..31 દિવસની પંક્તિઓ + **કુલ** પંક્તિમાં `=SUM(...)` + **રોજનું સરેરાશ** પંક્તિ.
* હેડર ફ્રીઝ, AutoFilter, A4 લેન્ડસ્કેપ પ્રિન્ટ ફિટ.
* ફરી બનાવવું હોય તો:

```bash
pip install openpyxl
python3 form8/make_template.py       # ચાલુ મહિના માટે
python3 -c "import form8.make_template as t, os; print(t.build('form8/2026-10.xlsx', 2026, 10))"
```

## 3. ડેવલપર માટે

* એપ એક જ ફાઇલમાં છે — કોઈ બિલ્ડ સ્ટેપ નહીં, કોઈ npm ડિપેન્ડન્સી નહીં.
* `.xlsx` ફાઇલ બ્રાઉઝરમાં જ લખાય છે (`makeZip` + `buildSheetXml`),
  એટલે ઓફલાઇન પણ કામ કરે. શીટમાં ગુજરાતી ટેક્સ્ટ અને `SUM()` ફોર્મ્યુલા આવે.
* ટેસ્ટ (Node + openpyxl થી બનેલી ફાઇલ ચેક થાય):

```bash
node form8/test-export.js
python3 -c "import openpyxl; print(openpyxl.load_workbook('form8/_test_out.xlsx').active.dimensions)"
```

## 4. જરૂરી ફેરફાર

આ એપ સામાન્ય HMIS-શૈલીના દૈનિક આંકડા માટે ડિફોલ્ટ કોલમ સાથે આવે છે
(OPD/IPD/રેફરલ/લેબ/ડિલિવરી/ટીકરણ). તમારા Form-8 ના ચોક્કસ કોલમ મને આપો તો
ડિફોલ્ટ કોલમ એ જ પ્રમાણે સેટ કરી દઈશ — ત્યાં સુધી કોલમ સેટિંગમાંથી જાતે બદલી શકાય.
